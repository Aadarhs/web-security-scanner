OWASP Top 10 Scanner Reference Guide

SQL Injection

SQL Injection (SQLi) is a code injection technique that exploits security vulnerabilities in an application's software by inserting malicious SQL statements into entry points. Our scanner tests for:

  • Error-based SQLi - Database error messages reveal information
  • Boolean-based blind SQLi - Inferring data from true/false responses
  • Time-based blind SQLi - Using sleep/delay commands
  • UNION-based SQLi - Data extraction via UNION statements

OWASP Category: A03:2021 – Injection

Remediation: Parameterized queries, prepared statements, input validation

Cross-Site Scripting (XSS)

XSS enables attackers to inject client-side scripts into web pages viewed by other users. Our scanner detects:

  • Reflected XSS: Malicious script reflected off web server
  • Stored XSS: Malicious script stored on the server
  • DOM-based XSS: Vulnerability in client-side script

OWASP Category: A03:2021 – Injection

Remediation: Context-aware output encoding, CSP headers, input sanitization

CSRF

Cross-Site Request Forgery (CSRF) forces authenticated users to execute unwanted actions. Our scanner checks:

  • Missing anti-CSRF tokens in forms
  • Missing SameSite cookie attributes
  • Weak or absent clickjacking protections

OWASP Category: A01:2021 – Broken Access Control

Remediation: CSRF tokens, SameSite cookies, Referer/Origin validation

Security Headers

HTTP security headers protect against common attack vectors. Our scanner checks for:

  • CSP: Content Security Policy
  • HSTS: Strict Transport Security
  • X-Frame-Options: Clickjacking protection
  • X-Content-Type-Options: MIME sniffing prevention
  • Referrer-Policy: Referrer information control
  • Permissions-Policy: Feature restriction

OWASP Category: A05:2021 – Security Misconfiguration

Authentication

Weak authentication mechanisms are a primary attack vector. Our scanner tests for:

  • Default/weak credentials acceptance
  • Missing Secure flag on session cookies
  • Missing HttpOnly flag on session cookies
  • Login endpoint exposure

OWASP Category: A07:2021 – Identification and Authentication Failures

Remediation: Strong password policies, MFA, secure cookie configuration
